# Diaspora Bill Pay (Stellar)

Pay a school, hospital or landlord in Nigeria from abroad in USDC. Funds sit in a Soroban escrow and release **only** to a verified provider's wallet, with an on-chain receipt for the sender. Providers cash out to naira through a Stellar anchor (SEP-24).

Built for the Stellar Buildathon (Nigeria chapter), Nov 2026.

Work in progress. Web app (Next.js) + Soroban contract on Stellar testnet.
